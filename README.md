### [ESP32 × ROS 2 × NVIDIA Isaac Sim](https://github.com/Vvp999/esp32-isaac-sim-teleop)
**Hardware-in-the-loop robot teleoperation.** A physical joystick on an ESP32 drives a simulated Jetbot in **Isaac Sim 6.2** over **ROS 2 Jazzy**, while an LCD "robot face" reacts to how you drive.

- ⚡ ESP32 firmware (C++): calibrated 50 Hz sampling + custom serial protocol
- 🐍 Python `rclpy` bridge → `/cmd_vel` with fail-safe stop
- 🧩 Isaac Sim OmniGraph: ROS 2 subscriber → differential controller → wheel joints
- 👀 LCD1602 eyes with custom glyphs: gaze, blink, moods
- 🛣️ Next: robot arm, RViz odometry, synthetic-data YOLO
